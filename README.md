# شذرات للمنح

منصة عربية متكاملة للمنح والخدمات الطلابية، مبنية باستخدام Next.js وTypeScript وTailwind CSS.

## الحالة الحالية

المرحلة التأسيسية الأولى: الهوية البصرية، الصفحة الرئيسية، قائمة المنح، صفحات التفاصيل، وتهيئة SEO الأولية.

## الأمان

- لا ترفع ملف .env.local إلى GitHub.
- الصلاحيات والـXP والطلبات الحساسة يجب التحقق منها في الخادم.
- تُضاف مفاتيح Firebase كمتغيرات بيئة في منصة الاستضافة.

## مراحل التطوير

1. الواجهة العامة ونظام المنح.
2. Firebase والمصادقة والصلاحيات.
3. لوحة الإدارة وWorkflow النشر.
4. الخدمات والطلبات والإشعارات.
5. XP والمهمات والإحالات والمكافآت.
6. الاختبارات والمراقبة والنسخ الاحتياطي والنشر.
